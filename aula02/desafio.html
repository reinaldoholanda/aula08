Desafio de criação de filmes indicados ao Oscar Você vai escolher um ano da edição do Oscar e criar uma página principal e uma página para cada filme indicado. Estrutura da página inicial - Título - Parágrafos explicando o objetivo da premiação, as categorias existentes e o contexto do ano escolhido da edição - Uma imagem da capa de cada filme indicado. Essa imagem vai ter o link para a página do filme específico (navegação interna) Página do Filme específico Estrutura - Título - Se ganhou categoria adicione um subtitulo indicando que foi o ganhador - Parágrafos explicando o filme - Uma imagem da capa do cada filme - Lista dos Atores do filme - Lista Técnica - Link para site oficial - Link para algum review do filme Ao final um link para voltar para a página inicial
